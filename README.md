# SÍMIO — builds

Instaladores do protótipo **SÍMIO: O Trono das Raízes** (Windows). O código-fonte fica em um repositório privado.

- **Última versão:** veja `latest.json`. O jogo instalado consulta esse arquivo ao abrir e se atualiza sozinho. Desde a 0.0.4 a atualização baixa só os dados do jogo (`.pck`), sem executável novo.
- **Instalar manualmente:** baixe o instalador em `windows/` (o Windows avisa "editor desconhecido": Mais informações → Executar assim mesmo).
